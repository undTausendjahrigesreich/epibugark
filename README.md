# 💬 [Epitaphi] — Issues & Bug Tracking

Welcome to the official issue tracker for

**⚡️ Epitaphi 🧙‍♂️**! 

This repository is dedicated entirely to collecting user feedback, tracking bugs, and discussing new feature ideas.
---

## 🚀 How to Report an Issue

Before creating a new issue, please **[search existing issues](../../issues)** to see if someone has already reported the same problem.

### 🐛 Reporting a Bug
If you found something broken, please open a **[New Issue](../../issues/new)** and include:
- **Steps to reproduce:** What did you click or do before it broke?
- **Expected vs. Actual Behavior:** What should have happened, and what actually happened?
- **Environment Details:** Your browser (e.g., Chrome, Safari) and device (e.g., Mac, Windows, iOS).
- **Screenshots/Console Errors:** (Optional, but super helpful!)

### 💡 Requesting a Feature
To propose new features or modifications, open a **[New Issue](./issues/new)** using this format:

- **Proposal:** Concise summary of the feature or modification.
- **Use Case:** Clear explanation of why this functionality is required.
- **Functional Requirements:** How the feature should operate or look.
- **Priority Level:** Blocker / Major / Minor / Nice-to-have.

---

## 📌 Rules & Guidelines

- **No Sensitive Info:** Never post passwords, API keys, or personal private data in an issue.
- **Stay On Topic:** Keep discussions focused on the reported issue or feature request.
- **Be Kind, Rewind:** Submit appropriate and professional cases, or your feature will be denied.
